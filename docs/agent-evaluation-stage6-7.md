# 阶段 6–7：本地评测中心

## 如何使用

重启当前 mini-harness UI 服务，点击聊天页顶部的「评测中心」，或访问同一端口的 `/evaluation`。

1. 选择文件夹，再选择其中一个 JSON/JSONL；也支持直接选择单个文件。只把选中文件发送到本机，最大 8 MiB。
2. 点击「校验与预览」。检查问题、论文绑定版本、标准答案及预算。格式与活动论文版本不符时拒绝执行。
3. 选择规则模式或 DeepEval 模式，核对页面显示的模型与发送范围，勾选本次操作授权后启动。
4. 运行过程中可以取消；同步模型调用采用协作取消，需要等待当前请求返回或超时。刷新页面不会停止后台任务。
5. 历史运行可以继续未完成用例，或仅重评分而不重跑 Agent。异常退出后的 running 状态可点击「恢复中断状态」；其他进程持有 worker 锁时拒绝恢复。

DeepEval 模式需要在 `.mini-harness/evals/judge.json` 放置配置，格式参考 `docs/evaluation/judge.example.json`。其 `api_key_env` 指定的密钥必须存在于服务进程的环境变量中；不接受浏览器传入密钥或任意目标 API 地址。默认规则模式无需 judge 配置。未设置语义阈值不会自动判定质量通过。

## 诊断与比较

- 运行页分别展示执行状态、质量判定、完成数；用例可查看历史执行尝试。
- 用例详情包含输入、参考标签、实际回答、评分理由，以及 Turn → Step → 模型/工具/RAG 明细。
- 输入输出快照按需读取，验证路径范围、长度和 SHA-256；读轨迹不会修复或改写执行日志。
- RAG 展示两路候选、融合排名、证据取舍与上下文引用。分数不是正确概率；原文按绑定版本及物理页码打开，删除或更新的原文可能不可用。
- 全部注册指标都可查看；未实现指标明确标为 planned，缺失值不填零。已有运行时耗时与 token 还可在 Step 明细查看。
- 基线对比展示质量、耗时、token 及指标均值差异和样本数。数据集、配置、指标版本或 judge 配置不一致会提示。均值按有效 metric target 计算，不是 case 加权均值；比较不代表统计显著性。
- 支持 JSON/CSV/HTML 报告导出。人工复核独立、追加保存，不覆盖自动评分。选中用例可导出回归数据集草稿，仍需人工审核标签。

## 实现职责

`evaluation/ui_service.py` 管理本次授权、校验、串行后台执行、取消、重评分和复核；一次启动只领取对应 run，不会执行其他排队任务。`evaluation/report.py` 只读聚合持久化数据，处理追踪引用、比较与安全导出。`ui.py` 提供沿用本地 Host/token 保护的 API；`evaluation.html` 与 `evaluation.js` 是独立评测页，动态内容通过 textContent 渲染。

## 验证与边界

本地模拟模型验证了授权拒绝、配置变化拒绝、队列隔离、取消、报告和 step 关联、文件完整性校验、导出转义、人工复核和 HTTP token。评测测试集 35 项通过，后续修改又通过 4 项 UI 专项和 6 项原聊天 UI 回归；JavaScript 语法与 Git 差异检查通过。浏览器已核对评测历史与 Turn/Step 展开。

本次未调用真实外部模型，也未证明 Agent 质量达标。阶段 8 的人工基准、阈值校准和真实评测仍未实施。历史列表最多 200 次运行；单个轨迹预览限制 64 MiB、单个 artifact 32 MiB，超限显示不可用。正常聊天和评测可共存，但共享本地 RAG 资源时耗时会受竞争影响，正式性能比较建议暂停聊天及论文导入。
