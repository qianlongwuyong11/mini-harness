# RAG 请求投影去重

2026-10-15：已实现请求投影，尚未重跑真实模型对照评测。

- Session 的工具结果仍按原逻辑持久化，超大输出继续由 Spill 外存并保留引用；不增加另一份正文事件。
- 本轮执行工具后、Spill 之前，仅在内存保存调用 ID 对应的轻量结果元数据。
- 构造模型请求时，本轮 search_papers/read_section 成功结果投影成状态、证据 ID、数量和说明；正文只通过 EvidenceLedger 快照注入。
- 本轮 list_papers 和工具错误保留可供规划与恢复的信息，其他工具不受影响。
- 新 turn 清空账本及轻量元数据。历史 RAG 工具结果投影为历史标记，不再携带工具正文和旧目录；工具调用/result 的配对 ID 保留。
- 每次请求附带应用提供的当前选择范围。历史问答仍可用于理解追问，但旧引用不是本轮可引用证据；需要细节应在当前范围重新读取。
- 恢复旧会话时，没有本轮账本的工具结果按历史处理，不自动恢复为新证据。

核心代码：src/mini_harness/rag/projection.py；集成点：rag/plugin.py 的 capture_result、begin 和 guard。

验证：RAG Agent 12 项、评测运行器 9 项本地测试通过；覆盖单份正文、跨轮清理、Session 不变、恢复会话、Spill/Prune、引用修复及非 RAG 工具隔离。未把本地测试通过率视为真实 Agent 通过率。

本次没有改变原评测预算或请求前预算预估策略。历史 assistant 回答仍保留，可能包含上一轮的少量引用/转述；本次清理对象是历史 RAG 工具正文，不宣称跨轮历史中完全没有论文内容。旧的冻结实验继续保留，新的实际评测应创建独立实验目录。
